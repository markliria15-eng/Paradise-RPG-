==================================================
ANIMAÇÕES A CRIAR
==================================================

Criar/atualizar as animações do player para cada classe:

idle_down  -> frame 0
walk_down  -> frames [1, 2, 3, 2]

idle_up    -> frame 4
walk_up    -> frames [5, 6, 7, 6]

idle_left  -> frame 8
walk_left  -> frames [9, 10, 11, 10]

idle_right -> frame 12
walk_right -> frames [13, 14, 15, 14]

FPS recomendado:
- Guerreiro: 7 FPS, caminhada pesada
- Arqueiro: 9 FPS, caminhada leve e ágil
- Maga de Fogo: 8 FPS, caminhada elegante/mágica

Loop:
- Todas as animações de walk devem ficar em loop.
- Idle pode ficar parado em 1 frame.

==================================================
REGRAS DE MOVIMENTO
==================================================

Quando o player estiver parado:
- Usar idle da última direção olhada.

Quando o player andar para baixo:
- Reproduzir walk_down.

Quando o player andar para cima:
- Reproduzir walk_up.

Quando o player andar para esquerda:
- Reproduzir walk_left.

Quando o player andar para direita:
- Reproduzir walk_right.

Se movimento diagonal existir:
- Priorizar a direção com maior força no eixo.
- Se abs(x) > abs(y), usar left/right.
- Caso contrário, usar up/down.

func update_class_sprite(class_name: String) -> void:
    match class_name:
        "guerreiro":
            $Sprite2D.texture = preload("res://assets/characters/classes/guerreiro/guerreiro_walk_sheet_4x4_256x256.png")
        "arqueiro":
            $Sprite2D.texture = preload("res://assets/characters/classes/arqueiro/arqueiro_walk_sheet_4x4_256x256.png")
        "maga_de_fogo":
            $Sprite2D.texture = preload("res://assets/characters/classes/maga_de_fogo/maga_de_fogo_walk_sheet_4x4_256x256.png")

    $Sprite2D.hframes = 4
    $Sprite2D.vframes = 4

func update_walk_animation(velocity: Vector2, class_name: String) -> void:
    var moving := velocity.length() > 0.1

    if moving:
        if abs(velocity.x) > abs(velocity.y):
            if velocity.x < 0:
                last_dir = "left"
            else:
                last_dir = "right"
        else:
            if velocity.y < 0:
                last_dir = "up"
            else:
                last_dir = "down"

        play_walk_anim(class_name, last_dir)
    else:
        play_idle_anim(last_dir)

func play_idle_anim(dir: String) -> void:
    match dir:
        "down":
            $Sprite2D.frame = 0
        "up":
            $Sprite2D.frame = 4
        "left":
            $Sprite2D.frame = 8
        "right":
            $Sprite2D.frame = 12
